## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Edit the content in `index.html` and styling in `style.css` as needed.

No build tools or package installation are required.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes deploying, visit `https://YOUR-USERNAME.github.io`.

## Personalize before publishing

- Confirm that the email address and contact details are correct and that you want them public.
- Add a professional headshot if desired.
- Add project descriptions and links in a new Projects section when you are ready to showcase completed work.
- Add certificate images or PDFs inside `assets/certificates/` and link to them from the Certifications section.
- Add your GitHub and LinkedIn profile URLs when available.
